# Mohammad Ullah: Portfolio

Open `index.html` in a browser to preview.

## Edit your content
Open `index.html` and scroll to the `DATA` block near the bottom. Change the text inside the quotation marks.
Anything in [square brackets] is a placeholder.

## Add your files
- `images/profile.jpg`: your profile photo (`.jpg` and `.jpeg` both work)
- `images/project-1.jpg` ... `project-6.jpg`: project pictures (in the order of the project cards)
- `images/internship-1.jpg`, `internship-2.jpg`: internship photos
- `assets/cv.pdf`: your CV (the Download CV button)

## Publish on GitHub Pages
1. Create a repository named `yourusername.github.io`.
2. Upload everything in this folder (keep `images` and `assets`).
3. Settings > Pages > choose the main branch. Your site opens at https://yourusername.github.io

## Contact form
The form opens the visitor's email app with the message filled in. For a form that sends without an email app, create a free Formspree form and ask Claude to connect it.
